# 前端风险触发测试速查

本文件替代旧的 `client_flutter/write` 原型草稿，作为前端手工测试入口。
完整 API 命令和联调说明见 `../docs/risk-test-cases.md`。

## 1. 测试池

- 城市只用：`北京 / 上海 / 西安`
- 人物只用：`小a / 小b / 小c / 小d / 小e / 小f`

## 2. 前端手工测试

### 场景 A：低风险放行

- 入口：`首页 -> 转账`
- 输入：
  - 收款人：`小b`
  - 金额：`300`
  - 城市：`上海`
- 预期：
  - 预检通过或低风险提醒
  - 可直接确认转账

### 场景 B：中风险二次质询

- 入口：`首页 -> 风险演示`
- 预置：
  - 收款人：`小c`
  - 金额：`8000`
  - 城市：`北京`
- 预期：
  - 出现二次质询弹窗
  - 弹窗列出需要补充说明的点
  - 弹窗展示回答样例

### 二次质询建议回答

标准结构：

- `关系`：收款人是我线下认识的朋友 / 同事 / 家人
- `用途`：归还借款 / 日常往来 / 代付房租
- `风险排除`：不涉及验证码、安全账户、屏幕共享、远程控制

可直接使用的完整示例：

`收款人是小c，是我线下认识的朋友，这次转账用于归还借款，不涉及验证码、安全账户、屏幕共享或远程控制。`

## 3. 高风险拦截说明

以下场景更适合走 API 精准触发，因为前端默认摘要较固定：

- `safe account`
- `verification code`
- `安全账户`
- `验证码`
- `马上转`
- `账户冻结`

请直接参考 `../docs/risk-test-cases.md` 中的 S3-S6。
