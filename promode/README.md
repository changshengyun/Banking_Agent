# promode

> 这个文件夹用于沉淀 Codex 在本项目中的固定执行约束。  
> 每次进入实现任务前，先读这里，再读 `plan.md`。

## 阅读顺序

1. `promode/codex_execution_rules.md`
2. `promode/development_requirements_summary.md`
3. `plan.md`
4. `MVP.md`
5. `nowthink.md`
6. `math.md`

## 作用

- 固化你在对话中明确过的协作要求
- 减少每轮重复沟通
- 保证后续执行风格、文档同步和多 Agent 拆分保持一致

## 说明

- `promode/` 不定义版本目标，不替代 `plan.md`
- `plan.md` 仍是唯一活动执行计划
- 历史协作要求汇总见：`promode/development_requirements_summary.md`
